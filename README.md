# Melvin's Premium Developer Portfolio

A modern, professional portfolio website for **Melvin** — AI Automation Engineer & Systems Developer. Built with Next.js, TailwindCSS, Framer Motion, and optimized for high-end SaaS founder aesthetic.

## 🚀 Features

- **Modern Dark UI** - Professional engineering aesthetic with dark theme
- **Smooth Animations** - Framer Motion powered interactions and transitions
- **Responsive Design** - Mobile-first approach, fully responsive
- **Dashboard Aesthetic** - Systems engineering inspired layout
- **Premium Components** - Cards, badges, buttons with glassmorphism effects
- **Animated Backgrounds** - Subtle grid patterns and floating elements
- **Interactive Projects** - Featured and additional project showcases
- **Contact Form** - Fully functional contact section
- **Performance Optimized** - Optimized for speed and user experience

## 📋 Sections

1. **Hero** - Animated introduction with floating analytics cards
2. **About** - Professional background and expertise overview
3. **Stats** - Impact metrics with animated counters
4. **Skills** - Categorized technical expertise
5. **Featured Projects** - Detailed showcase of major projects
6. **Additional Projects** - Grid of 12+ additional projects
7. **Automation Systems** - AI workflow and automation section
8. **Agency** - ToBro Agency introduction
9. **Strengths** - Core capabilities and engineering philosophy
10. **Contact** - Contact form and social links
11. **Footer** - Professional footer

## 🛠 Tech Stack

- **Next.js** 14 - React framework with SSR/SSG
- **TailwindCSS** 3 - Utility-first CSS framework
- **Framer Motion** 10 - Production animation library
- **Lucide React** - Beautiful icon library
- **TypeScript** - Static type checking

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/melvin-ph/portfolio.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🚀 Deployment

Optimized for deployment on Vercel, Netlify, or any Node.js hosting.

```bash
# Deploy to Vercel
vercel deploy

# Or build and deploy manually
npm run build
```

- **Content** - Section components in `src/components/sections/`
